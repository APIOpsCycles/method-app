# Presentation assets

The default slide header uses only the **APIOps Cycles** method symbol, sourced from `packages/apiops-design-system/src/assets/brand/apiops-cycles-logo.svg`. `apiops-cycles-logo.svg` preserves the editable source; `apiops-cycles-logo.png` is its transparent export for the shared slide renderers. Do not substitute the separate APIOps community logo or the standalone wordmark for this header symbol.

`capability-cycle-route.svg` is an original simplified teaching diagram based on the eight stations in `apiops-cycles-method-data` 4.2.1. Its PNG is used in slides. The diagram retains APIOps Cycles / Osaango Ltd attribution under CC-BY-SA 4.0. It is not the API Productization metro map.

The fictional supplier-payment examples are illustrative, not client artefacts or measured results. Keep canvas notices, scene attribution and the source notes when reusing assets. See `visual-prompt.txt`, the slide speaker notes and the package README for further provenance and reuse guidance.
