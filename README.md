# APIOps Cycles site

The production site is a statically generated Astro application.

## Applications

- `apps/site/` contains the Astro source. `apps/site/astro.config.mjs` sets `output: "static"`; React is reserved for explicitly hydrated interactive islands.

## Configuration

Set `PUBLIC_SITE_ORIGIN` to the public origin used for Astro canonical URLs and the static host's `site` setting. During migration, `NEXT_PUBLIC_SITE_ORIGIN` and `SITE_ORIGIN` remain supported as fallbacks. The default is `https://apiopscycles.com`.

## Presentations

`/presentations` provides an English-language library with an 8-slide overview, an 11-slide financial-services case study and a 28-slide technical introduction. Each edition has a Reveal.js online viewer with a text transcript, editable PowerPoint/PDF downloads, a portable Reveal.js ZIP, speaker notes and the shared developer source kit. Relevant cycle and station pages link to the library. Online and exported Reveal.js slides use real HTML text, lists and tables generated from the same released source; old `#slide-N` links remain supported.

`packages/apiops-presentations/` maintains shared slide JSON, edition selections, branding, layouts and export scripts separately from method data. See its README for partner branding and release instructions. Versioned, reviewed release assets are retained under `releases/`; `npm run sync:presentations` checks their SHA-256 hashes and copies the current release to `public/presentations/`. Root development and production builds run this sync automatically. Normal site builds do not need Typst or regenerate decks.

Presentation source: `npm run presentations:build -- --edition apiops-overview --name my-overview`. Prepare a new release with `npm run presentations:release` after installing the fonts and Typst CLI described in the presentation package.

## Generated method data

`/llms.txt` is generated by Astro from the current method catalog and locale list. It introduces the method vocabulary and guides agents to public pages and structured JSON, including graph joins and licensing. Public pages link to it with `rel="describedby"`.

Public cycles, stations, lines, roles, and published resources have `.md` references generated from the same method data, including canvas guidance. Each language has an `/index.md` method document index and `/llms-full.txt` combined download (for example `/fi/index.md` and `/fi/llms-full.txt`). Contextual station documents contain changes to shared guidance, linked explicitly; shared sections and resource bodies are not copied into every journey. These exports cover method content, not every site page or interactive workspace state. HTML method pages advertise their Markdown reference with `rel="alternate" type="text/markdown"`.

`npm run prepare:local-data` writes internal build artifacts to `generated/method/` and publishes only the JSON integration surface under `public/data/`. The root build scripts run it automatically before building the Astro site.

## Commands

```bash
npm install
npm run dev          # Astro development server
npm run prepare:local-data # build and sync local package data
npm run build        # static Astro production artifact in dist/
npm start            # preview the built Astro site locally
npx playwright install chromium # install the browser used by end-to-end tests
npm run test:e2e     # run Playwright end-to-end tests
```
